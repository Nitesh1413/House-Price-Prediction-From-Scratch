# Real Estate Price Prediction Engine: A First-Principles Approach

A comprehensive statistical learning suite built entirely from scratch in a unified architecture. This project implements Simple, Multiple, and Polynomial Regression models without relying on high-level machine learning libraries like `scikit-learn`. It focuses on fundamental mathematics, manual gradient descent optimization, and strict architectural control over data pipelines.

---
